Ausführungsrichtlinie anpassen

Erlaubt die Ausführung von PowerShell-Skripten:

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

PowerCLI Installation

Installiert VMware PowerCLI Module:

Install-Module -Name VMware.PowerCLI -Force -AllowClobber

PowerCLI Zertifikatsprüfung deaktivieren

Für Entwicklungs-/Testumgebungen:

Set-PowerCLIConfiguration -InvalidCertificateAction Ignore -Confirm:$false

SSH-Modul Installation

Für Proxmox SSH-Verbindungen:

Install-Module -Name Posh-SSH -Force

Installation überprüfen

Prüft installierte Module:

Get-Module -ListAvailable VMware.PowerCLI, Posh-SSH
